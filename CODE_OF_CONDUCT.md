# Code of Conduct

Thread Messenger is a welcoming project for contributors of all backgrounds. This Code of Conduct applies to issues, pull requests, discussions, and any other project space.

## Our ground rules

- **Be respectful.** Disagree with ideas, not people. Use clear, kind language.
- **Assume good faith.** Ask for clarification before assuming the worst; remember that impact still matters, even when no harm was intended.
- **Be constructive.** Review code, not contributors. Give specific, actionable feedback.
- **Respect privacy.** Do not post passwords, tokens, private messages, or someone else's personal details in public issues.

## Not acceptable

Harassment, threats, personal attacks, slurs, hateful or sexualized content, doxxing, deliberate disruption, spam, and discriminatory behavior are not welcome here.

## Reporting

For a code or documentation problem, open an issue with the relevant repository template. For a sensitive conduct concern, use the private contact details listed on the project's **Contact page** (`/contact`) or in the repository's contact information. Do not include secrets or highly sensitive details in a public issue.

## Enforcement

Maintainers may edit or remove content, close issues or pull requests, and temporarily or permanently restrict participation when these rules are broken. We will aim to explain the reason and give a chance to correct course when appropriate. Reports will be handled as privately as possible.

Thanks for helping keep this project friendly and useful.
