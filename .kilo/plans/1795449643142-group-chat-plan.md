# Group Chat Production Hardening Plan

## Summary
Group chat MVP is implemented. Remaining work hardens backend/realtime, completes typing/search UI wiring, and validates a clean migration from scratch.

## Scope
- Backend: migrations, RLS, RPC validation, rate limits, indexes.
- API/types: keep contract in sync.
- UI: `src/features/chat/**`, `ChatPage`, `ChatListPage`.
- Tests: unit + integration against Docker/Supabase.

## Remaining issues to fix
1. Migration reliability: `supabase migration up` reported “up to date” after SQL errors. Validate with `supabase db reset` and a clean `migration up`.
2. Realtime flake: subscriber sometimes misses first message. Add subscription-ready wait, bounded retry, and keep `onResync` gap recovery.
3. Typing presence: add update policy, rate limit `set_typing`, and wire input change to `setTyping` every 3s.
4. Search: rate-limit `search_users_by_prefix` and `search_messages`; validate non-empty query and max length.
5. Group settings: verify creator-only RLS/RPC paths, post-action navigation, and member refresh.
6. Input validation: trim/limit title, description, usernames; dedupe; enforce 20-member cap atomically.
7. Indexes: active membership, messages by conversation, typing cleanup.
8. Error normalization: map new RPC errors to existing `ApiErrorCode`.

## Implementation order
1. Clean DB reset and reapply migrations; fix any SQL errors.
2. Harden RPCs (rate limits, validation, least-privilege).
3. Fix realtime subscription readiness/retry.
4. Wire typing indicator and message search UI.
5. Expand integration tests: prefix search, description, typing, creator-only remove/delete, leave, max cap.
6. Run typecheck, unit, integration, manual mobile/dark-light.

## Validation
- `supabase db reset` then `supabase migration up`.
- `npm run typecheck`, `npm run test`, `npm run test:integration`.
- Manual: group create, add/remove, rename, description, leave/delete, typing, search, mobile 44px, dark/light.

## Decisions
- Full hardening in scope.
- Typing TTL 6s, refresh 3s.
- Search across all active conversations.
- No uploads; Identicon/initials.
- Creator-only rename/add/remove/delete; members leave.
- Max 20 members.

- None blocking.
