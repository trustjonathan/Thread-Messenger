# Group Chat Fixes + Identity Plan

## Summary
Fix duplicate group rows, group header duplication, description visibility, member search/1:1 navigation, sender identity in group messages, and editable seed-based avatars.

## Root causes
- Duplicate groups: `list_conversations()` joins `other_cm` for all conversations; groups multiply rows per member. Fix with direct-only lateral lookup.
- Header twice: ChatPage renders both `GroupHeader` and the normal `Avatar + h1` block. Render only one for groups.
- Description inactive: group description is loaded but not rendered in header/drawer. Render it under the group header and in the drawer.
- Search inactive: add-member search exists but needs to be the single group-list modal with clickable users.
- Avatars static: Identicon seed is hardcoded to user/conversation id. Add editable `avatar_seed` to profiles.

## Changes
1. Backend migration:
   - Replace `list_conversations()` so groups return one row; direct chats use lateral other-member lookup.
   - Add `profiles.avatar_seed text` and `update_avatar_seed(p_seed text)` RPC; expose `avatar_seed` in `getCurrentUser`/`listGroupMembers`/conversation mapping.
   - Add `ON CONFLICT DO NOTHING` in group member inserts.
2. ChatPage:
   - For groups render only `GroupHeader` (avatar + title + member count + description snippet); remove duplicate h1/avatar.
   - Load `listGroupMembers()` into a map; render avatar + display name + @username above each group message.
   - Tapping a member in the group list calls `getOrCreateDirectConversation(member.userId)` and navigates to `/chats/:id`.
3. GroupSettingsDrawer:
   - Single modal with member list + search; creator sees Add; everyone sees members.
   - Description shown for all; creator can edit.
4. Settings:
   - Add avatar seed/palette picker; save via `updateAvatarSeed`.
   - Use `avatar_seed` everywhere Identicon is rendered so changes propagate to groups/friends.
5. Cleanup:
   - Ensure one group row per conversation; add integration assertion.

## Implementation order
1. Migration: list_conversations fix, avatar_seed, update_avatar_seed.
2. Types/database/api mapping.
3. ChatPage header/description/sender identity/member navigation.
4. Drawer search/member click.
5. Settings avatar picker.
6. Tests + manual validation.

## Validation
- `supabase db reset` + `supabase migration up`.
- Integration: one row per group; add member; update avatar seed; 1:1 from member.
- Unit: group header/sender rendering.
- Manual: duplicate check, description, search, member click, avatar propagation, mobile/dark-light.

## Decisions
- Avatar editing: seed/palette only, no upload.
- Sender UI: avatar + display name + @username above each group bubble.
- Group header: single trigger opening member modal.
- Member click: start/open 1:1 without leaving group.
- Creator-only add/remove/rename/delete; members leave.
- Max 20 members.
